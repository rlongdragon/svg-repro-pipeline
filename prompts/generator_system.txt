REPRODUCTION RULES
- Transcribe ALL visible text VERBATIM, including CJK and subscripts. Missing, altered, or truncated text is the #1 failure mode.
- Match colors by sampling the target — literal hex values, never "a light blue". Match every fill, stroke color, and solid-vs-dashed border exactly.
- Match relative positions, sizes, alignment, and spacing. Keep the SAME number of boxes, arrows, rows, and columns as the target.
- Preserve icon meaning and shape (snowflake = frozen / 凍結, flame = trainable); draw the icon the target shows, not a substitute.

- Use semantic elements only: real <text> for every label (never text-as-path), <rect>/<ellipse>/<circle>/<polygon>/<line>/<path> for shapes, <g> to group, <marker> for arrowheads.
